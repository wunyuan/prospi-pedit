# prospi-pedit — eBaseball PRO SPIRIT 單機選手編輯器

給 Steam 版 **eBaseball パワフルプロ野球 PRO SPIRIT（プロスピ）** 用的圖形介面選手編輯器。

不用 Cheat Engine、不用背記憶體位址、不用打指令。**開遊戲 → 開 prospi-pedit → 左邊點選手 → 右邊拉滑桿**，改完立刻生效。

> **A GUI player editor for the single-player modes of eBaseball PRO SPIRIT (Steam).** Windows x64 only.

---

## ⚠ 用之前先看這五行

1. **只用在自己的單機／離線存檔**（栄冠ナイン、明星選手）。**不要用在連線對戰**——違反遊戲條款，有封號風險。
2. 它只改**遊戲執行時的記憶體**，不動遊戲檔案、不碰 Denuvo。
3. 所以**遊戲一關掉，所有修改就消失**，也**不會寫進存檔**。
4. 這同時是安全網：**改壞了關掉遊戲重讀存檔就全部還原。**
5. 風險自負。作者不對存檔或帳號問題負責。

## 快速上手（3 步）

1. 到 [Releases](../../releases) 下載 `pedit-windows-x64.zip`，解壓縮到任何資料夾。
2. **先開遊戲**，進到看得到選手名單的畫面。
3. 執行 `pedit.exe`。標題列出現綠色的「已附加 pid ○○○」就成功了。

接著在上面選模式：

| 按這個 | 什麼時候用 | 要等多久 |
|---|---|---|
| **栄冠(高中)** | 玩栄冠ナイン，要改自己的部員 | 馬上 |
| **明星選手(主角)** | 只想改自己操作的那位主角 | 約 5 秒 |
| **明星選手(全掃)** | 想改任何一位職棒選手 | 約 1 分鐘 |

左邊點選手，右邊就會出現他的所有數值。**拉滑桿或點按鈕就直接寫進遊戲了，沒有「儲存」按鈕。**

> 💡 **改完畫面沒變？** 這是正常的 —— 遊戲不會自動重畫。**切到別的選手再切回來**（或切換頁面）就看得到了。

## 我想做的事情是…

### 「我要讓栄冠的部員變強」

選 **栄冠(高中)** → 點選手 → 拉「能力值」那一區的滑桿。想全部拉滿就每項拉到 99。

球種也可以改：在「球種」區把球威、控球點到 **S**，變化量拉到 7。空的格子可以**直接選一個球種進去**，等於憑空多學一顆球。

### 「我要改明星選手的主角」

選 **明星選手(主角)**，它會自動找到你操作的角色。

如果用 **明星選手(全掃)**，同一位選手可能會出現**好幾份**（名字後面標 `×3`）。認明**名字前面有 ★ 的那一份**——那才是遊戲真正在用的。

> ⚠ **為什麼會有好幾份？** 遊戲在記憶體裡放了同一位選手的多份資料（不同用途、不同時間點的）。改到不對的那份，畫面可能當下有變，但打完一場比賽就被覆蓋回去了。
> 如果 ★ 那份改了還是沒用，標題列有 **◀ ▶** 可以當場換下一份試。

### 「改了能力值，打完比賽卻變回去」

**這是明星選手模式的正常機制**，而且 pedit 已經幫你處理好了。

明星選手模式真正存的是**練習累積的經驗值**，你看到的能力值只是算出來的結果。每次結算都會重算一次，所以只改能力值撐不過一場比賽。

pedit 在這個模式下**拉滑桿時會同時改經驗值**，所以改了就是永久的（到遊戲關閉為止）。你不需要做任何額外設定。

下面還有「成長經驗值」區可以更精細地控制：

* **目標能力值滑桿（0~99）**：想要 85 就拉到 85，它會算出需要多少經驗值 —— 不必無腦灌滿。
* **★ 全部灌到最大**：下次結算後所有能力變 99。
* **⚡ 立即套用結果**：不想等練習，直接把 99／175／99 寫進去。

### 「我要無限道具」

畫面最底下的「常規功能」勾選框，**勾了就一直有效**，不用再按任何按鈕：

| 勾選框 | 效果 |
|---|---|
| 栄冠：全道具 99 ＋ 使用不消耗 | 用掉會立刻補回 99 |
| 栄冠：解除「每人 1 個道具／書籍 5 本」 | 同一位部員可以一直用 |
| 栄冠：練習效果提升永久 | |
| 跨模式：共用道具全 99 | |
| 明星選手：解除道具使用上限 | |
| 明星選手：道具使用不消耗 | 這個是**按鈕**，按一次就生效到遊戲關閉 |

> ⚠ 栄冠的那幾個要**在看得到部員名單的畫面**才有效。離開栄冠模式後會自動停止，這是正常的。

### 「我要給選手原創球種（オリジナル変化球）」

在「球種」區把某一格改成**原創球種**，下面就會出現「↳ 原創內容」讓你挑。

壓縮檔內附 **36 種官方原創球種**（火の玉ストレート、ジャイロスプリット 之類，每個人都有的）。

**你自己用遊戲內編輯器做的球種**是你存檔獨有的，內附的庫裡不會有。按最上面那顆綠色的 **「⟳ 蒐集原創球種到球種庫」**，它會把目前載入的選手身上的原創球種全部收進來並存檔，之後就能套用到任何選手身上。

> 💡 **建議先切到「明星選手(全掃)」再按**，一次能蒐集到最多（介面上也會提示你）。
> 💡 連內附的 `origlib.json` 弄丟了也沒關係，按這顆就能重建一份。

### 「我要改特殊能力」

「特殊能力」分頁，全部 90 項都在：

* 上半 = **11 個等級能力**（短打、得分機會、對危機…），點一下升一級，超過最高會繞回最低；**右鍵**可以直接選。
* 下半 = **68 個變體能力**的勾選框。

> ⚠ **明星選手模式請先按「★ 等級全部拉到最高」**。原因：等級和旁邊的附加能力共用同一格資料，遊戲每次幫你升級時會把附加能力洗掉。拉到最高就不會再升級，附加能力才留得住。

## 疑難排解

| 狀況 | 怎麼辦 |
|---|---|
| 改了畫面沒變 | 正常。切到別的選手再切回來 |
| 標題列是紅字／橘字 | 遊戲沒開，或遊戲重開過。按**「重新附加」** |
| 遊戲重讀存檔後改不動了 | 選手資料換位置了。按**「重新附加」**再按**「重新整理」** |
| 栄冠模式一個部員都沒有 | 要在**看得到部員名單的畫面**才讀得到。離開栄冠模式後讀不到是正常的 |
| 編輯區整個變灰、不能動 | 保護機制：偵測到那個位置已經不是原本那位選手了（避免誤改別人）。按「重新整理」 |
| 明星選手改了，打完比賽變回去 | 確認你改的是 **★** 那一份；或用標題列的 **◀ ▶** 換一份試 |
| 球速拉不到 175 以上 | 上限就是 175。遊戲內部改得更高，但**實戰投出來還是 175**，沒有意義 |
| 原創球種只顯示「原創」沒有名字 | 球種庫是空的。按**「⟳ 蒐集原創球種到球種庫」** |

## 介面速查

**上排**：附加狀態 ／ 重新附加 ／ 模式切換 ／ 重新整理
**第二排**：⟳ 蒐集原創球種到球種庫 ／ 球種庫現況
**左欄**：選手清單（搜尋、只顯示投手、合併同名副本）
**右欄**：基本 → 擅長球路九宮格 → 能力值 → 特殊能力 → 球種
**底部**：常規功能（道具類勾選框）

清單上的標記：

* `P` `C` `1B` `2B` `SS` `LF`… ＝ 守備位置（顏色比照遊戲：投手紅、捕手藍紫、內野黃、外野綠）
* `★` ＝ 這份是明星選手的主角，**要編這份**
* `×3` ＝ 這位選手在記憶體裡有 3 份

## 從原始碼建置

需要 **Windows 版**的 Rust toolchain（host `x86_64-pc-windows-msvc`）。

```sh
cargo build --release
# 產物：target/release/pedit.exe
```

* **必須用 Windows 版的 Rust。** WSL／Linux 的 Rust 編不出能讀寫 Windows 行程記憶體的執行檔。
* `Cargo.lock` 把 `image` 釘在 0.25.5，因為 1.88+ 需要更新的 rustc。

`origlib.json`（球種庫）要跟 `pedit.exe` 放在同一個資料夾。

## 已知限制

* 只支援 **Windows x64**，只在 Steam 版測過。
* 遊戲大改版後，靠程式碼樣式搜尋的功能（道具使用不消耗）可能失效。資料位址目前跨版本沒變。
* 明星選手模式的選手資料**每次讀取存檔後都會換位置**，所以每次都要重新掃描。
* 同一位選手在記憶體裡有多份，pedit 用「有沒有成長經驗值結構」來挑主角那份，其餘用位址順序推測 —— 大多數情況正確，挑錯時用 ◀ ▶ 換。
